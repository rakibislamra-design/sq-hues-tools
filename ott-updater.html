    1Files you need

    Box 1: Fabric Plan: the last updated file (download it with the button above). Must be .xlsx, not .xlsb or .xls.

    Box 2: DOC -280+217: today's master, saved in Excel with values (open it, then press Save once). The tool reads only sheet 217.

    One file per box. Close both files in Excel before you upload.

    2Fixed names: don't rename

    Sheet names, in this order:

    Buyer Wise OTT Hit Rate → Fab Plan-Final → Date Wise Pivot -Hues

    DOC master: sheet 217 (other sheets aren't read).

    Fab Plan-Final: headers in rows 1–2, data from row 3. Column A (Buyer) must be filled on every row, because the data range ends at the last filled A cell.

    After the update, every line with a shortage (Balance to RFD below 0) is matched to 280 WIP batches by PO + fabric + shade / AOP design. Closed / PO Pending stock and Final Reject batches are never used.
