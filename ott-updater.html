    After the update, every line with a shortage (Balance to RFD below 0) is matched to 280 WIP batches by PO + fabric + shade / AOP design. Closed / PO Pending stock and Final Reject batches are never used.

    New columns after AX: Need Additional · Batch No · Color · Fabrication · Plan Qty Kg · Batch Position · H/S Status (280 H/s Pending) · Dye Batch (280 Dyebatch No) · Dye Date · Fin Date · Rcvd Date from Outside · RFD Date (280 Dyeing / Finishing / Received / RFD Date of the batch) · Dye Plan · Fin Plan · RFD Plan · Discussion · Remarks (filled by you; kept when the file is uploaded again) · Mill Name (Inhouse, or the outside mill from 280 — MN, Nice, Sadma, NRG…; a line without a batch takes its PO's mill) · Dyeing Mill. A line needing 2+ batches is split into one row per batch; total Req Qty stays the same.

    Dyeing Mill: follows the row, not the batch. A value already in the uploaded file (typed by you or from an earlier run) is never changed; the tool fills only blank cells. Dye/Fin/RFD Plan, Discussion and Remarks follow the Batch No (a new batch starts blank). It feeds the Dyeing Mill slicer on the Date Wise Pivot.

    Remarks (AG): when a batch's first line now has a different Agreed RFD Date (earlier or later) than in the uploaded file, the tool writes Old Date-dd/mm (its earlier date) there, after any note you typed. The note stays while the batch stays on that date, keeps the first old date if it moves again, and is removed from rows that no longer hold the batch.

    Rules: AOP lines show AOP Batch; outside batches still at the mill show the 280 Order No; KPK black outside = KPK-Outside-Black.

    Downloads: the final Fabric Plan (update + allocation) and, when box 4 is filled, the updated Line Plan-Foc-Aop-Hanger List_<date>.xlsx. If yesterday's file already has these columns, they are rebuilt, not repeated.

    Line Plan-FOC-AOP-Hanger (box 4), after the Fabric Plan update: first 280 is replaced by the DOC 280 and Hanger / FOC / PFP Plan are rebuilt from the WIP batches (the same step as the Master File page); then Batch Wise Line Plan is updated as below; pivots refresh and formulas recalculate when the file is opened.

    Line Plan-FOC-AOP-Hanger, sheet Batch Wise Line Plan: (1) a listed batch (Batch No) that is no longer in 280 is replaced by the 280 batch of the same order with the same Customer PO + Shade + Fabric/Yarn — first the same batch with another FY (FY25-26 → FY26-27), else the only such batch the line plan uses, else the only one with the same first two parts, else the only one not yet listed; the info columns are refreshed from 280 and Remarks gets Old batch-…. If none fits, Remarks gets Batch not in 280 …. (2) Every batch the line plan uses: Delivery Date = Agreed RFD Date of its earliest line, Rfd Date = Delivery − 4, Dyeing Date = Delivery − 6. (3) Line-plan batches not in the list are added at the bottom: Customer … Fabric/Yarn from 280, the sheet's formulas copied down, Line Plan Month from the delivery date. Excel recalculates when the file is opened, so paste the day's 280 into the file's 280 sheet as usual.
